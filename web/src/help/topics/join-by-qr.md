## Showing the code

- In a session, open the menu and choose **Share session** (it's under **Participants** and **Chat**). In **Participants**, it's under **Invite**, next to **Copy link**. Anyone in the session can open it.
- It shows a QR code of the session's link, the link itself, and **Copy link**.
- **Large** makes the code fill the panel, and on a wider screen the whole screen, so people can scan it from a projector or a shared screen. Choose **Large** again to go back.
- **Esc** or **X** closes it, and you're back where you were.

## Scanning it

- Point a phone's camera at the code and open the link it finds. It's the same as opening the link: you see **Join session**, type your name and choose **Join**. See [Starting and joining a session](help:sessions).
- Anyone who can see the code can join, just like anyone with the link.

## Privacy

- The code is drawn on your device from the session's link. Nothing is sent anywhere to make it, and nothing is stored.
- If a link is ever too long to fit in a code, the panel says so and you can still copy the link.
