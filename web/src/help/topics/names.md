Stickyard has no accounts. When you join a session, you type a name, and everyone in that session sees it next to your messages.

## Names are not verified

- You can type any name you like, up to 24 characters, and so can everyone else. Two people can even use the same name.
- Nobody checks a name, so a name in a session doesn't prove who wrote something.
- If it matters who said what, confirm it another way, for example out loud in the meeting.
- Each person also gets a coloured dot, chosen by the relay. The name is always shown next to it.
- This browser remembers the last name you joined with, so it's filled in next time.

## Anyone with the link can join

- A session link works for whoever has it. Share it only with the people you mean to invite.
- Don't type passwords or anything confidential into a session.
