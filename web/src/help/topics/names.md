Stickyard has no accounts. Joining a session isn't in this version yet; when it arrives, this is how names and links will work.

## Names are not verified

- You'll type any name you like, and so will everyone else.
- Nobody checks a name, so a name on the board doesn't prove who wrote something.
- If it matters who said what, confirm it another way, for example out loud in the meeting.

## Anyone with the link can join

- A session link works for whoever has it. Share it only with the people you mean to invite.
- Don't put passwords or anything confidential on a board.
