## Shapes, protocol v15 (v0.21.0)
- `PROTOCOL_VERSION = 15`; v14 pages get `version_mismatch`. One new object, the shape: `{ id, kind, x, y, w, h, text, fill, stroke, strokeWidth, strokeStyle, fontSize, bold, italic, underline, textColor, align, valign, z, rev, authorId }` (`shapeSchema`). `SHAPE_KINDS` text | rect | oval | diamond, fixed at creation (a text label is a shape with fill none and no border). Keys only: `SHAPE_FILLS` (none + `FRAME_COLORS`), `SHAPE_STROKES` (= `FRAME_COLORS`), `SHAPE_STROKE_WIDTHS` (none, thin, medium, thick), `SHAPE_STROKE_STYLES` (solid, dashed), `SHAPE_FONT_SIZES` (s, m, l, xl, 2xl, 3xl, 4xl; px in `SHAPE_FONT_PX`, mirrored by `--sy-shape-font-*`, test checks), `NOTE_TEXT_COLORS`, `NOTE_ALIGNS` (center, not centre), `SHAPE_VALIGNS`. `shapeDefaults(kind)` (text 240x48 no fill/border, l, left/top; rect and oval 200x120; diamond 200x160; boxed kinds neutral fill, thin solid border, centre/middle). `MAX_SHAPES_PER_ROOM` 50, `MAX_SHAPE_TEXT` 500 (`cleanShapeText` = note cleaning at that cap; `truncateCodePoints` never cuts a pair), `SHAPE_MIN_W/H` 40x24, `SHAPE_MAX_W/H` 2400x1600 (tokens `--sy-shape-min/max-*`, test checks), `clampShapeRect`/`clampShapePosition`.
- Client (strict): `shapeAdd { clientRef, kind, x, y }`, `shapeEdit { id, ...SHAPE_EDIT_FIELDS }` (text + `SHAPE_STYLE_FIELDS`, at least one, never kind), `shapeMove`, `shapeResize`, `shapeDelete`, `shapeBatch { ops, final }` (entries `checkShapeBatch`, exactly noteBatch's rules; `ops`, not `entries`). `itemsAdd` takes `shapes?` (`shapeItemSchema`); note and shape items may give `rank` (their place among the message's new notes and shapes; the web ranks every note and shape of a message that has shapes). `frameMove` takes `shapeIds?` (one 50-item cap shared with `noteIds`). Server: `shapesSnapshot { shapes }` (strict, right after `framesSnapshot` in the join step), `shapeAdded` (clientRef to the sender), `shapeUpdated`, `shapeMoved`, `shapeResized`, `shapeDeleted`, `shapesBatchApplied`, `frameMoved.shapes`, `itemsAdded.shapes` (left out when none). Errors: `shapes_full`; refs `shapeId`, `shapeIds` (also on a refused carrying `frameMove`). Every new client type is `BOARD_WRITES: true`. `ITEM_KINDS`/`ITEM_REFUSALS` gain shape/shapes_full.
- One stacking space: notes and shapes share z. `notesOrder` accepts shape ids and `notesOrdered` may report them (up to `MAX_NOTES_PER_ROOM + MAX_SHAPES_PER_ROOM` results); `zForNew` and renumbering at the bound run over both (worker `stackItems`, `restacked` returns `{ notes, shapes }`, `newOnTop`). Frames stay behind everything. Web: `topZ`, `reorderLocal` and `applyOrdered` (notes/board.ts) cover shapes; history restores sort notes and shapes together by z, frames last.
- Worker (`room.ts` `handleShape`, `handleShapeBatch`): last-write-wins, rev per stored change, unchanged edit = no write and no broadcast, unknown ids ignored, live moves/resizes relayed via `pendingShapes` (coalesced, never stored). Final `frameMove` carries notes and shapes by one `groupOffset`, 1 + N + M rows in one transaction. `handleItems` fills slots per kind and stacks notes and shapes by rank. `entriesOf` counts shapeBatch ops, carried shapes and added shapes.
- Stored schema `SCHEMA_VERSION = 9`: `CREATE TABLE IF NOT EXISTS shapes (...)`, every column but the key with a DEFAULT (the rectangle's: SQL can't give per-kind ones; every insert names every column). `NoteStore` `allShapes`, `getShape`, `shapeCount`, `insertShape`, `updateShape`, `deleteShape`, `applyShapeBatch`; `applyBatch`/`applyAdds`/`applyFrameMove` take shapes too. Off-board rows clamped on load, bad rows skipped. Tested against `worker/test/fixtures/schemaV8.ts` with v0.20.0's exact note and frame statements. Burial drops the table with the rest (tested).
- Web model `shapes/board.ts` (like frames: confirmed, clientRef, draft, dragging/resizing, apply*, rollback, `applyShapesSnapshot` merge by rev, `resyncShapes` keeps drafts, `discardUnconfirmedShapes` on a drop). `Board` gains `shapes`, `shapesRemoved`. `RoomSession`: `addShape`, `editShape` (text and/or style, only changed fields), `setShapeDraft`, `startShapeDrag`/`moveShape`, `startShapeResize`/`resizeShape`/`setShapeSize`, `deleteShape`, `editShapes` (several, paced on the frame-edit queue, one history step), `onShapeConfirmed`; history kind `shape`; `ItemInput` shape is `{ kind: "shape", shapeKind, ... }`.
- Canvas: `shapes/ShapeNode.tsx` (memo; inline SVG outline stretched with a non-scaling stroke; text in an inset area, `--sy-shape-inset-oval/-diamond`; an empty bare label gets `.sy-shape-empty` and the placeholder "Text", never stored; `ShapeActionsContext`; inline `textarea[data-shape-input]` editing: Enter = new line, Esc/blur commits, 500 cap, read-only while disconnected; arrows move, Alt+arrows resize, Delete asks if it has text; `NodeResizer` for one shape alone). Node `zIndex` = z, md and up editable only (`FrameView.shapes`, phones read-only). Styles: `shapes/style.ts` (var() only: `--sy-shape-<c>-fill`, `-stroke`, `--sy-shape-text-<ink>`, `--sy-shape-fg`, `--sy-shape-stroke-*`, `--sy-shape-dash`; every ink 4.5:1 on every fill and the board, borders and placeholder 3:1, both themes, tested). Minimap and fit include shapes.
- UI: palette "Shapes" category (`SHAPE_TILES`, panel only, `PaletteActions.addShape`, `PaletteContext.shapeReason` = `shapeToolReason` with the lock); a new shape starts editing (`uiStore.startShapeEdit`). `uiStore.shapes` (third set), `shapeSelected` (derived), `selectShape`, `toggleShape`, `renameShape`, `pruneShapes`, `shapeEdit`. Properties: `shapes/ShapeFields.tsx` (`ShapeFields` for one: Text, Text style via the generalised `TextStyleSection` (`sizes`, underline, valign, title), Shape look (not for text), Size, Order, Details; `ShapesFields` for 2+ shapes alone: shared style/fill/border, Text Mixed and disabled, size points to Match size). Fill swatches are named "<colour> fill" (the inks share colour names).
- Integration (all md and up): marquee takes shapes by partial overlap; Ctrl+A everything; `deleteKeyTarget` "shape" / "selection" (scope: the board, the board bar and the side panels, `onSidePanel` = `[data-side-panel]` on both asides; shortcuts too); a focused note's or shape's own Delete deletes the whole selection when it's one of several or outside it (`BoardCanvas.deleteWholeSelection`, the window key's rules), so Ctrl+A then Delete removes every note, frame and shape wherever focus is (`test/selectAllDelete.test.tsx`); `deleteSelection(noteIds, frameIds, shapeIds)` (shapes in one shapeBatch, report via `removalReportFor(kind, notes, frames, shapes)`), Clear board includes shapes; `carryPlan` carries shapes (shared cap, `looseShapes`); `startSelectionDrag(frameIds, noteIds, carry, shapeIds)` (notes and shapes without frames move as a selection drag too; one live batch per tick, notes and shapes taking turns); `duplicateSelection` copies shapes (`duplicateShapeInput`, stacking kept, `DUPLICATE_HINTS.shapesFull`); Order acts on notes and shapes; `arrange.ts` `mixedClamp` and `applyRects` send notes and shapes (frames still exclusive). Help: `text-and-shapes` topic. LIMITS.md "Text and shapes" section.
- Emoji picker (web only, part 5): `emoji/emoji.ts` (`EMOJI` 48 single-code-point emoji with names, `insertEmoji(value, start, end, emoji, fits)` at the caret or null past the cap, `withinChars`, `emojiKeyMove`, `laidOutColumns`, `EMOJI_FULL`), `emoji/EmojiPicker.tsx` (labelled `data-emoji-trigger` button with `aria-expanded`; panel `[data-emoji-picker]` role=group "Emoji", 44px buttons, one tab stop with arrows/Home/End, Escape and a choice return focus and the caret to the field; past the cap nothing changes and `data-emoji-full` says so; `float` keeps its events from the node; `slot` opens the form panel below the field; `intoEmojiPicker(relatedTarget)` lets edits in place survive focus moving into it, `onAway` commits when focus leaves it elsewhere), `emoji/EmojiToolbar.tsx` (NodeToolbar to the right of a note or shape edited in place; `floatPlacement` in EmojiPicker keeps the floating panel inside `.react-flow`: shifted left, narrowed, or above and scrolling, from measured rects, null without layout, tested; found with Chromium screenshots). Used by `InlineText` (the part last focused), `ShapeTextEditor`, `NoteFields` (Title, Body; shared 280 cap via `fitsCap`), `ShapeFields` (Text, 500) and `FrameFields` (Title, 60). Not in the frame header's title. Token `--sy-emoji-panel` (`max-w-emoji`).
